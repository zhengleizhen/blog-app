# improve-tech-intros

## Summary

把项目中每个技术的介绍写得更完整一些，增强读者对技术栈和功能实现的理解。

## Goals

- 在首页、文章详情页和相关组件中补充每项技术的背景说明
- 解释当前项目采用的主要技术：Vue、Vite、组件化、状态管理等
- 让技术介绍更明确，便于阅读和学习

## Scope

- 更新 `Home.vue` / `HomeView.vue` 中的技术说明
- 更新 `PostView.vue` / `ArticleDetail.vue` 中的文章与技术说明
- 补充 `NavBar.vue`、`BlogCard.vue` 等组件中的技术说明或备注
- 不包含新增大型功能、路由结构调整或业务流程变更

## Non-goals

- 不新增页面功能或按钮
- 不进行后端 API 改动
- 不重构整个应用架构

## Notes

这个变更主要是为了让项目文档与代码阅读体验更好，帮助后续维护者和学习者快速理解当前应用的技术选型与实现方式。
